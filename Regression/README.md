🏡 Regression — House Price / Land Value Predictor
Predicts property prices (ETB) from features like size, age, location, and construction details. Trains multiple encoding/scaling/algorithm combinations, benchmarks them, and serves predictions through both Gradio and Streamlit UIs.

How it works
train_and_save.py trains every combination of:
Encoding: One-Hot Encoding, Label Encoding
Scaling: StandardScaler, MinMaxScaler, None
Algorithm: Linear Regression, Ridge, Lasso, SVR, Random Forest, Gradient Boosting, MLP (Neural Network)
That's 42 trained pipelines, each scored on R², RMSE, and MAE. Everything (models, scalers, encoders, results table, best pipeline) is saved into pipeline_bundle.pkl.
gradio_app.py / streamlit_app.py load that bundle and provide:
A Predict tab — enter property details, pick any of the 42 pipelines, get an estimated price
A Benchmarks tab — chart and full table comparing all pipelines by R² score

Setup
From within this folder:

bash
pip install pandas numpy scikit-learn joblib gradio streamlit plotly
You'll also need houses_improved.csv in this folder (not included in the repo — supply your own dataset with the columns above plus a Price_ETB target column).

Usage
bash

# 1. Train all pipelines and save the bundle (only needs to be run once,

# or again if you retrain on new data)

python train_and_save.py

# 2a. Run the Gradio UI

python gradio_app.py

# 2b. Or run the Streamlit UI

streamlit run streamlit_app.py

Notes
Both apps let you switch between all 42 trained pipelines, so you can compare how different algorithms/encodings perform on the same input.
One-hot encoded categorical inputs are built by aligning to the exact training column set — no reliance on pd.get_dummies on a single row, which breaks with sparse/single-category inputs.
pipeline_bundle.pkl can get large depending on your dataset size, since it stores all 42 trained models. Consider adding it to .gitignore if it's too large for git.
